# Khurja@Gng - Handcrafted Pottery & Ceramics E-commerce Website

An e-commerce website showcasing handcrafted pottery and ceramics from Khurja, featuring the story of a scholar who started this online business to help local potters.

## Tech Stack

- React.jsx with Vite
- Tailwind CSS
- React Router DOM

## Features

- Home page with product categories and image slider
- Product listing with filters and sorting
- Product detail pages with image carousel
- Shopping cart and wishlist functionality
- Contact Us page with map
- About Us page with scholar story
- Request a Product page

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Set up environment variables:
```bash
# Copy the example env file
cp .env.example .env

# Edit .env and add your Firebase and Cloudinary credentials
```

3. Run development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

**Note:** Make sure to configure your `.env` file with Firebase and Cloudinary credentials before running the app. See `ADMIN_SETUP.md` for detailed setup instructions.
